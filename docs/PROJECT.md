# 뉴오잉게임 프로젝트

이 저장소는 토스 웹앱을 위한 **뉴오잉게임** 프로젝트다. 원조 오잉게임과는 분리된 별도 프로젝트이며, 짧고 반복하고 싶은 중독성 있는 게임 루프를 핵심 목표로 한다.

## 개발 원칙

- 모바일 우선으로 설계한다.
- 기존 드래그 조작감과 포인터 이벤트 흐름을 보존한다.
- 점수, 시간, 콤보, 버튼 문구는 HTML 텍스트로 유지한다.
- `360×780`, `390×844`, `430×932` 화면을 기준으로 테스트한다.
- Toss SDK, Firebase, 배포 관련 기능은 명시적인 요청 전까지 수정하거나 연결하지 않는다.
