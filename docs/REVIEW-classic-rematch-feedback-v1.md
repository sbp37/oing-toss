# 클래식 재도전 피드백 1차

## 후속: 첫 결과 별명 안내

- 기본 별명임이 확인된 사용자에게 결과/광고 후 한 번만 별명 팝업. 기존 사용자도 업데이트 후 첫 완료 게임에서 해당.
- 입력칸은 비워 두며 이름을 직접 정한 사용자에게는 자동 안내하지 않음.
- 표시 여부는 기기 localStorage에 보관. 앱 데이터 삭제 시 다시 표시될 수 있으며, 저장 차단 환경에서는 현재 세션만 기억.
- 나중에/뒤로가기/Escape로 닫기, 포커스 복원, 저장 실패 시 입력 유지, 중복 제출 방지.
- 결과 및 랭킹 양쪽에서 같은 팝업 사용. 결과를 떠나거나 다른 게임을 시작하면 지연된 안내 취소.
- 관련 테스트 41개 통과. 모바일 세 크기에서 빈 입력칸/팝업 표시와 넘침 없음 확인. 별명 API 실서버 테스트 대신 rankingDemo로 QA하여 사용자 기록은 변경하지 않음.

## 후속: 닉네임 안전 필터

- Firebase 랭킹 API에서 한글·영문 욕설, 초성 표현, 운영자 사칭을 차단.
- NFKC 정규화 뒤 숫자 삽입, 반복 글자, 영문 숫자 치환 형태도 함께 검사.
- 클라이언트 검사를 우회해도 서버의 `nicknameReason()`에서 거절.
- 정상 자동닉네임과 `시바견`, `병아리`, `자두냥` 같은 비슷한 일반 이름은 허용하는 회귀 테스트 추가.

기준: main `9050a9f` 위 Claude `16958bc`, `e83f812`.
작업 브랜치: `codex/classic-rematch-feedback-v1`.
main 머지, 원격 push, 배포, AIT 생성 없음.

## 변경

- 꼬리 판갈이에서 인접한 가로/세로 세 칸 답을 보호한다. 마지막 `1,1,8`을 직접 지워 싹쓸이할 수 있다.
- 성공/폭탄 경로 모두 한 번 찾은 정답 목록을 재사용한다.
- 도착 안내를 가리던 불가능한 분기를 제거한다.
- 폭탄 흔들림 종료를 CSS와 같은 440ms로 맞춘다.
- 작은 득점은 즉시 표시, 큰 득점은 카운트업. 화면 전환/일시정지/종료에 rAF 정리.
- 시작 시 5분 이내 조회한 전체 랭킹에서 가까운 상대 기록을 선택한다. 같은 점수는 1점 넘어야 돌파한다. 기존 공유 도전장의 동점 성공 규칙은 유지한다.
- 상대가 너무 멀거나 데이터가 없으면 내 최고기록/첫 목표로 대체한다. 진행 중 목표는 교체하지 않는다.
- 목표 달성 알림은 기록 돌파이며 실시간 순위 상승을 주장하지 않는다. 실제 순위는 기존 서버 응답만 사용한다.
- 결과에 실제 최고 콤보 개선 또는 가까운 목표를 표시한다. 새로 얻은 장면을 원래 그림 보기 창에서 바로 열 수 있다.
- 시뮬레이터의 잡은 아이템 처리 순서를 실제 게임과 맞춘다. 여전히 아이템 선택/생각 시간의 근사 모델이며 경제 보존의 증명은 아니다.

점수 공식, 시간 환급, 점수 규칙 버전, 저장키, leaderboard.js, SDK/vendor, 광고 로직은 변경하지 않았다.
수집과 콤보 보상은 기존 구현을 활용했다. 새 경쟁 모드와 보너스 수치 재조정은 이번 범위에 넣지 않았다.
