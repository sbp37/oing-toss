# 앱인토스(토스 웹앱) 제출 자료

앱 이름: **오잉게임** / Oing Game / `oing-game`

## 파일

| 파일 | 규격 | 용도 |
| --- | --- | --- |
| `icon-600.png` | 600×600 | 앱 아이콘. 원스토어에 올린 것과 같은 그림 |
| `thumbnail-1932x828.png` | 1932×828 | 목록 썸네일. 원스토어 그래픽 이미지 그대로 |
| `source/graphic-source.webp` | 1916×821 | 위 썸네일의 원본(원스토어에 올린 그래픽 이미지) |
| `01-home.png` | 636×1048 | 세로형 1 — 홈 |
| `02-play.png` | 636×1048 | 세로형 2 — 합 10을 묶는 순간 |
| `03-cards.png` | 636×1048 | 세로형 3 — 오잉 카드 수집 |

썸네일은 원스토어에 올린 그래픽 이미지 그대로다. 원본이 1916×821이라 목표
비율(2.333:1)과 사실상 같아서, 자르거나 덧대지 않고 크기만 키웠다. 다시
만들려면 `tools/build-toss-thumbnail.py`를 돌린다. 원본 비율이 달라지면 같은
도구가 알아서 좌우를 흐린 배경으로 채우는 쪽으로 넘어간다.

스크린샷은 게임을 실제로 띄워 찍었다. 판을 너무 비우면 숫자가 사라져 무슨
게임인지 안 보이므로, 숨은그림이 살짝 드러날 만큼만 지운 상태를 골랐다.

다시 뽑으려면 `tools/build-store-screenshots.mjs`와 같은 방식으로 뷰포트를
412×679(636×1048과 같은 비율)로 두고 찍은 뒤 줄인다.

## 꾸러미(.ait)

```sh
npm run build      # dist/client
npx ait build      # oing-game.ait
```

`apps-in-toss.config.mjs`가 `webBundleDir`을 `dist/client`로 가리키므로,
원스토어에 올린 안드로이드 앱과 정확히 같은 파일이 담긴다.

`.ait`는 빌드 산출물이라 저장소에 두지 않는다(`.gitignore`).

## 앱 설명 문구

### 한 줄 소개 (짧은 설명)

> 붙어 있는 숫자를 드래그해서 합 10을 만드는 2분짜리 두뇌 게임.

### 상세 설명

> **합이 10이 되게 묶으세요. 딱 그거 하나면 됩니다.**
>
> 나란히 붙은 숫자들을 손가락으로 쓱 감싸면, 합이 10일 때 사라집니다.
> 규칙은 이 한 줄이 전부인데, 판이 넓어질수록 눈이 바빠집니다.
>
> **2분 안에 몇 점까지 갈 수 있을까**
> 판을 다 비우면 시간을 돌려받고 더 넓은 판으로 넘어갑니다. 연달아
> 성공하면 콤보가 붙어 점수가 불어나고, 잘 풀릴수록 판이 커져
> 마지막 10초는 손이 떨립니다.
>
> **막히면 도와주는 것들**
> 셔플과 힌트를 쓸 수 있고, 판 위에 폭탄·시계·네잎클로버가 가끔
> 나타납니다. 폭탄은 주변을 한 번에 날리고, 시계는 시간을 벌어줍니다.
>
> **모으는 재미**
> 기록을 세울 때마다 오잉 카드가 열리고, 고양이의 모험 장면이
> 한 칸씩 채워집니다. 숨겨진 카드도 몇 장 있습니다.
>
> 계정도, 로그인도 필요 없습니다. 켜면 바로 시작합니다.

### 심사 참고

- 로그인·회원가입 없음. 개인정보를 모으거나 밖으로 보내지 않는다.
- 기록은 기기 안(localStorage)에만 남는다.
- 결제·광고 없음.
- 권한 요청 없음.
- 랭킹은 토스 게임센터에 점수만 올린다(한 판당 1회).

실제로 배포한다(자세한 건 그 파일 주석에).
