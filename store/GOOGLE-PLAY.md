# 구글플레이 출시 준비

원스토어 절차는 `store/ANDROID.md`에 있다. 이 문서는 구글플레이 전용이고,
겹치는 부분(키 만들기, AAB 빌드)은 그쪽을 가리킨다.

**이 문서의 모든 사실은 저장소 코드에서 확인한 것이다.** 추측한 곳은 그렇게
적어 두었다.

---

## 0. 다음 구글플레이 버전에는 AdMob 광고가 들어간다

이게 이 문서 전체의 전제라 맨 앞에 둔다.

토스 랭킹과 친구 초대는 계속 토스 전용이다. Google Play 앱에는 네이티브
AdMob 어댑터를 별도로 연결한다. 일반 웹에서는 광고가 나오지 않는다.

| 기능 | 구글플레이 빌드에서 |
| --- | --- |
| 보상형 광고(이어하기·도움팩) | **나온다** (사용자가 선택할 때만) |
| 전면 광고 | **세 판 완료 뒤 다음 판을 누르는 전환에서만** |
| 토스 게임센터 랭킹 | **안 나온다** |
| 친구 초대 리워드 | **안 나온다** |
| 게임 본체·카드·기록·도전장 | 전부 그대로 |

실제 광고는 `OING_ADMOB_APP_ID`, `OING_ADMOB_REWARDED_ID`,
`OING_ADMOB_INTERSTITIAL_ID` 세 값이 모두 있는 빌드에서만 켜진다. 하나라도
없으면 SDK 호출이 비활성화된다. 개발 중 테스트 광고는
`OING_ADMOB_ENABLE_TEST_ADS=true`를 명시한 빌드에서만 켠다.

## 1. 데이터 보안(Data safety) 양식

콘솔에서 묻는 순서대로 적었다. **근거를 같이 적었으니 코드가 바뀌면 여기도
같이 고칠 것.**

### 데이터를 수집하거나 공유하나요? → **예**

게임 개발자의 자체 서버로 플레이 기록을 보내지는 않지만, Google Mobile Ads
SDK가 광고 제공·측정·부정 사용 방지를 위해 기기 밖으로 정보를 처리할 수 있다.
따라서 광고 SDK 기준으로 데이터 보안 양식을 다시 작성해야 한다. 콘솔의 AdMob
데이터 공개 안내와 현재 SDK 버전을 기준으로 최종 확인하고, 예전의
"수집하지 않음" 답을 그대로 재사용하지 않는다.

| 확인한 것 | 결과 |
| --- | --- |
| `fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon` | 없음. `js/adapters.js`의 `fetch` 두 곳은 **꾸러미 안의 카드 그림 파일**을 읽어 공유에 붙이는 용도다 |
| 외부 도메인 참조 | 없음 (`sbp37.github.io`는 공유 링크 글자일 뿐, 앱이 호출하지 않는다) |
| 분석 SDK | 없음 |
| 광고 SDK | Google Mobile Ads SDK + UMP 있음 |
| 소셜 로그인 | 없음 |
| 자체 서버·계정 | 없음 |

`js/telemetry.js`가 "telemetry"라는 이름을 쓰지만 **전송이 아니다.**
`localStorage`에 최근 50판을 적어 두고 밸런스 확인에 쓸 뿐, 읽는 것도 기기
자신뿐이다. 이름 때문에 오해하기 쉬우니 심사에서 물어보면 이렇게 답한다.

### 앱이 기기에 저장하는 것 (수집이 아님 — 참고용)

전부 `localStorage`이고 전부 기기 안에만 있다.

- 최고 점수, 최근 점수 목록, 누적 통계(플레이 판 수·지운 칸·모은 고양이 등)
- 설정(소리·음악·진동), 별사탕 개수, 본 장면/카드
- 도전장 점수(`?vs=`로 받은 숫자 하나)

게임 코드가 이름·이메일·전화번호·위치를 만들거나 읽지는 않는다. 광고
식별자와 광고 관련 기기 정보는 Google Mobile Ads SDK가 처리할 수 있다.

### 권한

`android/app/src/main/AndroidManifest.xml`에 있는 것이 전부다.

| 권한 | 왜 |
| --- | --- |
| `INTERNET` | Capacitor 웹뷰와 광고 요청 |
| `VIBRATE` | 타일을 지울 때의 진동 (설정에서 끌 수 있다) |
| `AD_ID` | Google Mobile Ads SDK가 병합하는 광고 식별자 권한 |

위치·연락처·저장소·카메라 권한은 없다.

### 개인정보처리방침 URL

```
https://sbp37.github.io/oing-toss/privacy.html
```

Google Play 광고 처리 내용까지 반영했다. 광고가 들어간 AAB를 올리기 전에
이 변경이 라이브 개인정보 처리방침에도 배포됐는지 확인한다.

## 2. 스토어 등록 문구

**남의 앱 이름을 넣지 않았다.** "사과게임" 같은 다른 게임 이름을 메타데이터에
끼워 넣는 것은 구글플레이 정책 위반이고, 심하면 등록 거부나 삭제로 이어진다.
같은 검색 수요는 일반 낱말(합 10, 10 만들기, 숫자 지우기)로 받는다.

### 앱 이름 (30자 제한)

```
오잉게임 - 숫자 합 10 퍼즐
```
(공백 포함 17자)

### 짧은 설명 (80자 제한)

```
사각형으로 묶어서 합이 10이면 뿅! 2분 안에 몇 점까지 갈 수 있을까냥?
```
(공백 포함 42자)

### 자세한 설명 (4000자 제한)

```
숫자를 사각형으로 묶어 합이 10이 되면 사라집니다.
규칙은 이 한 줄이 전부예요. 설명서도, 튜토리얼 열 페이지도 필요 없습니다.

■ 2분 한 판
한 판이 2분입니다. 지하철 한 정거장, 라면 익는 동안, 엘리베이터 기다리며
딱 한 판. 짧게 끊어 즐기기 좋게 만들었어요.

■ 판을 다 지우면 시간이 늘어납니다
칸을 남김없이 지우면 새 판이 열리고 시간이 더해집니다. 잘할수록 오래
플레이하게 되는 구조라, 실력이 늘수록 한 판이 길어져요.

■ 묶을수록 점수가 커집니다
두 칸보다 다섯 칸이, 다섯 칸보다 연속으로 이어가는 콤보가 훨씬 큽니다.
급하게 두 칸씩 지울지, 큰 묶음을 노리고 기다릴지 — 매 순간이 선택입니다.

■ 고양이와 함께
보드 곳곳에 고양이가 숨어 있습니다. 함께 지우면 데려올 수 있어요.
모은 고양이는 정원을 채우고, 별사탕을 주면 좋아합니다.

■ 오잉 카드 아홉 장
오래 플레이한 사람만 볼 수 있는 그림 카드가 아홉 장 있습니다.
첫 판을 끝내면 한 장, 그 다음은 조금씩 어려워집니다.

■ 친구에게 도전장
내 점수를 링크로 보내면, 받은 친구는 그 점수를 넘어야 할 목표로 들고
게임을 시작합니다. 넘으면 되받아칠 수 있어요.

■ 인터넷 없이도
한 번 받으면 비행기 모드에서도 플레이됩니다.
계정도, 로그인도, 개인정보 입력도 없습니다.

숫자 퍼즐 · 두뇌 게임 · 합이 10 · 10 만들기 · 숫자 지우기 · 캐주얼 퍼즐
```
(공백 포함 약 640자)

### 카테고리·등급

- 카테고리: **게임 > 퍼즐**
- 태그: 퍼즐, 캐주얼, 두뇌
- 콘텐츠 등급 설문: 폭력·성적 내용·욕설·도박·약물 **전부 없음**,
  사용자 간 소통 **없음**(채팅·댓글 기능이 없다), 위치 공유 **없음**,
  개인정보 수집 **없음** → 전체이용가가 나온다

## 3. 그래픽 자료

| 항목 | 구글 요건 | 지금 상태 |
| --- | --- | --- |
| 앱 아이콘 | 512×512 PNG, 32비트 | `assets/icons/app/icon-512.png` ✅ |
| 그래픽 이미지 | 1024×500 PNG/JPG | `store/google-play/feature-graphic-1024x500.png` ✅ |
| 휴대전화 스크린샷 | 2~8장, 16:9 또는 9:16, 320~3840px | `store/screenshots/*.jpg` 7장 (732×1300) ✅ |
| 태블릿 스크린샷 | 선택 | 없음 (건너뛰어도 됨) |

**그래픽 이미지는 만들어 뒀다.** 토스용 1932×828은 비율이 2.33:1이라 구글의
2.048:1과 안 맞는데, 늘려 맞추면 그림이 뭉개진다. 원본
(`store/toss/source/graphic-source.webp`, 1916×821)에서 좌우를 각각 108px씩
깎아 가운데를 살렸다 - 로고·고양이·"같은 짝을 더해 10을 만들어요"·타일 예시가
전부 남아 있다. 다시 만들려면:

```sh
python3 - <<'EOF'
from PIL import Image
im = Image.open('store/toss/source/graphic-source.webp').convert('RGB')
W, H = im.size
TW, TH = 1024, 500
new_w = int(round(H * (TW / TH)))
left = (W - new_w) // 2
im.crop((left, 0, left + new_w, H)).resize((TW, TH), Image.LANCZOS) \
  .save('store/google-play/feature-graphic-1024x500.png', 'PNG', optimize=True)
EOF
```

## 4. 업로드 절차

### 4-1. 업로드 키

`store/ANDROID.md`의 "1. 업로드 키 만들기"를 그대로 따른다.
**원스토어 키와 같은 것을 써도 되고 새로 만들어도 된다.** 구글은
Play App Signing을 쓰므로, 여기서 만드는 것은 "업로드 키"일 뿐이고
배포용 서명 키는 구글이 따로 만들어 보관한다.

### 4-2. 빌드

```sh
npm run android:aab      # dist/client 갱신 -> cap sync -> bundleRelease
```

산출물: `android/app/build/outputs/bundle/release/app-release.aab`

> 이 저장소가 도는 클라우드 컨테이너에서는 구글 SDK 서버(`dl.google.com`)가
> 막혀 있어 AAB를 대신 구울 수 없다. **로컬에서 실행할 것.**

빌드 전에 `android/app/build.gradle`의 `versionCode`를 올린다. 구글은 같은
`versionCode`를 두 번 받지 않는다. **구글플레이 첫 업로드를 위해 8로 올려
두었다**(versionName 1.1.1). 다음 업로드부터는 직접 올릴 것.

`targetSdkVersion`은 36이라 현재 요건을 넘는다. 요건은 해마다 오르므로
언젠가 올려야 한다: <https://support.google.com/googleplay/android-developer/answer/11926878>

### 4-3. ⚠️ 제일 먼저 확인할 것 — 클로즈드 테스트 요건

**다른 걸 하기 전에 이것부터.** 여기 걸리면 일정이 통째로 달라진다.

구글은 **개인 개발자 계정**에 "정식 출시 전 비공개 테스트를 일정 인원 ·
일정 기간 이상" 요구해 왔다. 인원수와 기간은 여러 번 바뀌었으므로
**콘솔에서 직접 확인할 것.** 여기에 숫자를 적어 두면 낡은 정보가 된다.

확인하는 곳:
- 콘솔 왼쪽 메뉴 → **테스트 및 출시 → 프로덕션** 에 들어가면, 요건이 걸려
  있는 계정에는 "프로덕션 출시 전 비공개 테스트를 완료해야 합니다" 같은
  안내가 뜬다. 안 뜨면 해당 없음.
- 도움말: <https://support.google.com/googleplay/android-developer/answer/14151465>
  (링크가 404면 콘솔 도움말에서 "비공개 테스트 요건"으로 검색)

걸린다면 순서가 이렇게 된다.
1. 먼저 앱을 만들고 등록정보·설문을 다 채운다
2. **비공개 테스트** 트랙에 AAB를 올린다
3. 테스터를 이메일 목록이나 구글 그룹으로 등록한다
4. 요구 기간을 채운다 (그동안 앱은 테스터에게만 보인다)
5. 그 뒤에 프로덕션 출시 버튼이 열린다

### 4-4. 콘솔 절차

콘솔: <https://play.google.com/console>

**1) 앱 만들기**
- 앱 이름: 2항의 이름
- 기본 언어: 한국어
- 앱 또는 게임: **게임**
- 무료 또는 유료: **무료** (한 번 무료로 만들면 유료로 못 바꾼다)

**2) 앱 설정 — 왼쪽 메뉴의 체크리스트를 위에서부터**

| 항목 | 답 | 근거 |
| --- | --- | --- |
| 앱 액세스 권한 | 모든 기능을 제한 없이 사용 가능 | 로그인이 없다 |
| 광고 | **예, 광고 포함** | 보상형 + 자연스러운 전환의 전면 광고 |
| 콘텐츠 등급 | 설문 → 2항대로 전부 "없음" | |
| 타겟층 | 만 13세 이상 | 아동 타깃은 규정이 크게 는다 |
| 뉴스 앱 | 아니요 | |
| 코로나19 접촉자 추적 | 아니요 | |
| 데이터 보안 | **광고 SDK 기준으로 수집·공유 항목 신고** | 1항과 AdMob 공개 안내 |
| 정부 앱 | 아니요 | |
| 금융 기능 | 아니요 | |

- 데이터 보안 도움말:
  <https://support.google.com/googleplay/android-developer/answer/10787469>
- 콘텐츠 등급 도움말:
  <https://support.google.com/googleplay/android-developer/answer/9859655>

**3) 스토어 등록정보** — 2항의 문구, 3항의 그림
- 규격 도움말:
  <https://support.google.com/googleplay/android-developer/answer/9866151>

**4) AAB 업로드** — 4-2의 빌드 결과물
- 첫 업로드 때 **Play 앱 서명**에 동의하게 된다. 우리가 만든 키는 "업로드
  키"가 되고, 실제 배포 서명은 구글이 맡는다. 업로드 키를 잃어버려도
  재설정할 수 있다는 것이 이 방식의 장점이다.
- 도움말: <https://support.google.com/googleplay/android-developer/answer/9842756>

**5) 출시** — 비공개 테스트 → (요건 충족) → 프로덕션

## 5. 출시 뒤에 할 일

- **AdMob 실광고 전환** — 앱 ID와 보상형·전면 광고 단위 ID를 GitHub
  Actions 시크릿에 넣고, UMP 메시지·광고 포함 여부·데이터 보안 양식을
  제출 전에 함께 확인한다. ID가 없으면 광고는 비활성화된다.
- **Play Games Services 리더보드** — 토스와 달리 **일간/주간/전체 순위가
  기본으로 딸려 온다.** 우리 서버가 필요 없다. Capacitor에서 쓰려면 다리가
  필요한데, 지금 있는 플러그인은 검증이 필요하다:
  - `@idleflowgames/capacitor-play-games` 0.2.1 — Capacitor 8 지원, 다만
    버전이 낮다
  - `capacitor-play-games-services` 2.0.1 — Capacitor 5용, **우리와 안 맞음**

  사람이 붙기 시작한 뒤에 하는 것이 순서다. 유입 0인 상태의 순위표는
  비어 있는 표일 뿐이다.
