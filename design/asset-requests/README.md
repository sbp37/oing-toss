# 에셋 요청 큐

Claude Code가 이미지 에셋이 필요할 때 이 폴더에 요청서를 만든다. Codex는 `status: open`인 요청서만 처리한다.

- 파일명: `<YYYY-MM-DD>-<짧은-이름>.md` (예: `2026-08-14-item-magnet-icon.md`)
- 처리한 요청서는 지우지 않는다. `status`만 `done`으로 바꾸고 산출 파일을 기록한다.
- 처리할 수 없으면 `status: blocked`으로 두고 이유를 적는다. 임의로 다른 결과물을 내지 않는다.

## 프로젝트 에셋 규칙

- 배포 포맷은 lossless WebP. PNG 원본은 `assets/source/` 또는 `design/**/source/`에만 남긴다.
- 배경은 완전 투명 알파. 크로마키로 만들었으면 잔여 초록 픽셀까지 제거한다.
- 타일·아이콘 마스터는 512×512, 데코는 256×256을 기본으로 한다. 화면 표시 크기보다 충분히 커야 한다.
- 숫자, 점수, 시간, 콤보, 버튼 문구는 이미지에 넣지 않는다. 전부 HTML 텍스트로 렌더링한다.
- 기존 시럽 타일(`assets/ui/tiles-syrup-v4/`)과 고양이(`assets/characters/`)의 밝고 맑은 톤, 도톰한 하이라이트를 기준 스타일로 삼는다.
- 기존 파일을 덮어쓰지 않는다. 개선판은 새 버전 폴더로 만든다.
